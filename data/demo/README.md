# Demo dataset

Subset of **15 Amazon Electronics products** extracted from the bootcamp preprocessing pipeline.

- **File:** `meta_Electronics_sample.jsonl`
- **Format:** JSONL (one JSON object per line)
- **Use case:** local development, tests, and reproducing the RAG pipeline without downloading multi-GB files

For the full dataset, download the Amazon Reviews 2023 metadata from the official source and place the files in `data/` (ignored by git).
